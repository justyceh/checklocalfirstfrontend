# Check Local First

A full-stack web platform that helps users discover and support local businesses while giving business owners the tools to manage their online presence.

🌐 **Live Website:** https://checklocalfirst.com

## Tech Stack

* React & Next.js
* JavaScript
* Express.js
* Supabase
* PostgreSQL
* SQL
* Vercel
* Render

## What I Built

* Designed and implemented the PostgreSQL database schema using SQL.
* Built a REST API with Express.js.
* Integrated Supabase for authentication and database management.
* Developed middleware for authentication, route protection, and request validation.
* Implemented security best practices for protected endpoints and sensitive data.
* Built responsive frontend pages with React and Next.js.
* Deployed the frontend on Vercel and the backend on Render.
